# ar-chimie
Visualisation AR de molécules 3D

## Cellule végétale 3D

Dossier [`cellule-vegetale-3d/`](cellule-vegetale-3d/) : cellule végétale 3D interactive pour les TP de physiologie végétale.

- Vue éclatée par étapes : paroi, membrane, noyau, organites, intérieur des chloroplastes et du noyau
- Fiches pédagogiques pour 18 structures, plan de coupe, quiz
- Modes « Élodée » (cellule chlorophyllienne) et « Oignon rouge », vue microscope, cellules voisines
- Réalité augmentée sur téléphone : WebXR (Chrome Android) et AR Quick Look (Safari iPhone/iPad)

Avec GitHub Pages activé (Settings → Pages → branche `main`, dossier `/`), la page est servie à :
`https://dooms750.github.io/ar-chimie/cellule-vegetale-3d/`
La RA ne fonctionne qu'en https, ce que GitHub Pages fournit.
